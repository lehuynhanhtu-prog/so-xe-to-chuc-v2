Bản Web đầu tiên: dữ liệu dùng namespace và thư mục V2 riêng, không tự đọc dữ liệu ứng dụng cũ. Kiến trúc đăng nhập không cần Google cho NSD sẽ được hoàn thiện ở bước backend Apps Script tiếp theo.

Phạm vi hiện tại

  • Đường dẫn GitHub Pages và nhận diện V2 riêng.
  • File và thư mục Drive mới mang định danh organization-v2.
  • Không chuyển tài khoản, xe hoặc giao dịch từ bản cũ.
